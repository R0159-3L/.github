# .github

This repository contains organization-wide GitHub configuration files for RICOH 3L.

## Contents

- **profile/README.md**: Organization profile page visible on our GitHub organization
- **CODE_OF_CONDUCT.md**: Code of conduct for all RICOH 3L projects
- **CONTRIBUTING.md**: Contribution guidelines for all RICOH 3L projects
- **ISSUE_TEMPLATE/**: Issue templates for bug reports and feature requests
- **PULL_REQUEST_TEMPLATE.md**: Pull request template for all repositories

## About RICOH 3L

RICOH 3L (R0159-3L) is committed to delivering high-quality open source projects and fostering a collaborative community.

For more information, visit our [organization profile](https://github.com/R0159-3L).
